II. Solving Inference & Routing Bottlenecks: Decisions API & Deferred Tier

Across the inference layer, teams often tell us that using a generative model just to parse JSON routing flags is slow and fragile. / On November eleventh, we launched the Gemini Decisions API (`gemini-decision-1`) in AI Studio. / Instead of generating text token by token, it evaluates up to one thousand closed-ended questions against a single 256K multimodal input in one forward pass—returning calibrated probabilities in 150 to 250 milliseconds at ten cents per million input tokens and zero output token cost. / Pair that with our new Deferred Tier at half the PayGo rate for background jobs, and you reduce both routing overhead and peak-hour 429 throttling.

在推理路由层，研发团队常反映用生成式模型输出 JSON 来做条件路由既慢又不稳定（fragile）。11 月 11 日我们在 AI Studio 推出了 Gemini Decisions API（gemini-decision-1）：它不逐个 token 生成文本，而是在一次 forward pass 中针对单个 256K 多模态输入评估多达 1,000 个封闭式问题，150–250ms 返回经过校准（calibrated）的概率，input 每百万 token $0.10，output 不计费。再搭配按 PayGo 半价计费的 Deferred Tier 处理后台任务，可以减少路由开销和高峰期的 429 限流（throttling）。

To see how this lands in production, look at Bloomberg. / On November tenth, Agent Retrieval—Vector Search 2.0—added Advanced Text Search in Public Preview, bringing boolean queries, boosting, and stemming to close the gap with legacy Solr and Lucene clusters, backed by zero-pipeline managed ingestion and 99.99% active/active availability. / Bloomberg already runs this stack inside its Terminal ASKB assistant for live transcript and document search— / which shows that enterprise teams can move past operational inertia and run RAG on one governed platform.

看一个生产环境案例：Bloomberg。11 月 10 日 Agent Retrieval（Vector Search 2.0）上线 Advanced Text Search（Public Preview），支持 boolean 查询、boosting 与 stemming，缩小了与传统 Solr/Lucene 集群的差距，并提供无需自建 pipeline 的 managed ingestion 和 99.99% Active/Active 可用性。Bloomberg 已在 Terminal 助手 ASKB 中用这套检索服务搜索实时 transcript 与文档，说明企业可以摆脱旧架构的运维惯性（inertia），把 RAG 放到统一受治理的平台上。

还有第二条底层（underlying）规则需要书面告知你们采购，避免年底 true-up 时产生误解：credits 能减少 CFO 实际支付的现金账单，也会消耗当月 FSP 额度，但由 credits 冲抵的金额不计入底层 EA 年度 commit 的消耗（does not retire the underlying commit）。先把这一点讲清楚（upfront），可以避免 Q1 对账分歧，也方便你们按真实预期用量测算现金承诺额。
