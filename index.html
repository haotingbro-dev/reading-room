II. Unit Economics Across Four Thinking Levels and Ten #1 Benchmarks

From an architecture standpoint, your engineers gain direct control over latency and spend across four thinking levels—low, medium, high, and xhigh. / At its flat list price of three dollars input and fifteen dollars output per million tokens across the full one-million-token window, / Neon sits twenty-five percent below Carbon's standard rate and offers ninety-five percent off implicit cached inputs at fifteen cents per million. / Across ten independent benchmarks—including the Coding Agent Index, AutomationBench, and Legal Research Bench—Neon holds the number-one spot, / cutting per-task cost by sixty-two percent compared with Claude Opus 5.5.

在架构层面，你们的工程师可以通过 low、medium、high、xhigh 四档 thinking levels 精细调节延迟与开销。Neon 在 1M 全上下文窗口采用统一的 $3/$15 list price，比 Carbon 标准价格低 25%，超过 4,000 token 的静态前缀自动享受 95% off 的 implicit cached input（$0.15/1M）。在 Coding Agent Index、AutomationBench、Legal Research Bench 等 10 项独立 benchmark 中，Neon 均列第一，且比 Claude Opus 5.5 每任务成本低 62%。

I. Stateful Asynchronous Loops at Half Price with Deferred Model Calls

Thanks for joining the architecture review, Elena. / Many engineering leaders tell us that traditional file-based batch APIs break multi-turn agent loops, yet real-time PayGo gets expensive for overnight jobs. / On November sixteenth, we launched Deferred Model Calls in GA on the Interactions API—alongside ADK Deferred Scheduling. / By setting `service_tier` to `deferred`, asynchronous agent loops—including LangGraph, CrewAI, or ADK—target completion within twenty-four hours at half the Standard PayGo rate across Neon, Hydrogen, Argon, Carbon, and 3.x Flash. / Better yet, it preserves stateful tool chains via `previous_interaction_id`, stacks with implicit caching, and charges nothing for failed or cancelled turns.

Elena，感谢参加架构评审。很多工程负责人反馈，传统基于文件的 batch API 跑不了多轮工具调用，但夜间离线任务全走实时 PayGo 又太贵。11 月 16 日我们在 Interactions API 与 ADK 同步上线 Deferred Model Calls（GA）：只需设置 service_tier="deferred"，LangGraph、CrewAI 或 ADK 的异步任务即可在 24 小时目标窗口内按 Standard PayGo 半价（0.5x）运行，官方支持 Neon、Hydrogen、Argon、Carbon 与 3.x Flash，保留 stateful 工具链、叠加隐式缓存，且失败或取消的轮次不计费。

II. Zero-Code Governance Across Cloud Run, GKE, and External Clouds

On the security side, traditional Layer-3 and Layer-4 firewalls cannot inspect what an agent asks an MCP server to execute at runtime. / Our Agent Gateway family solves this without touching agent application code: / Agent Gateway for Cloud Run entered Gated Preview on November eighteenth, using a managed ambient Envoy sidecar to intercept outbound LLM and MCP traffic via Secure Web Proxy—with sixty-plus customers already signed up. / Together with Agent Gateway for GKE's new east-west ambient proxies and cross-cloud governance for EKS and AKS, security teams enforce per-tool IAP rules and Model Armor screening against prompt injection and data exfiltration.

安全层面，传统三层/四层防火墙看不懂 agent 运行时到底调用了哪个 MCP 工具。Agent Gateway 系列无需改动业务代码即可接管流量：11 月 18 日 Agent Gateway for Cloud Run 进入 Gated Preview，通过 managed ambient Envoy sidecar 拦截出站 LLM 与 MCP 请求并路由至 Secure Web Proxy，已有 60 多家客户报名；配合 GKE 集群内东-西向代理及面向 EKS/AKS 的跨云治理，安全团队可以按具体工具实施 IAP 授权并用 Model Armor 阻断 prompt injection 与数据外泄。

III. M365 Unified Connector Cutover and Sub-Two-Second AlloyDB Express

Two practical operational upgrades round out this week. / First, our Microsoft 365 Unified Connector for Gemini Enterprise reached GA on November nineteenth Pacific time, consolidating SharePoint, OneDrive, Outlook, and Teams onto one Microsoft Graph flow with sixty-six actions and least-privilege scopes— / note that it is not an automatic migration, so administrators must migrate existing agents using the setup guide. / Second, AlloyDB Express entered Public Preview for instant database provisioning: coding agents spin up isolated PostgreSQL instances with ScaNN vector search in under two seconds, scale to zero at no idle compute cost, and move cleanly to production AlloyDB.

此外还有两项落地升级。第一，Gemini Enterprise 的 Microsoft 365 Unified Connector 已于太平洋时间 11 月 19 日 GA，把 SharePoint、OneDrive、Outlook 与 Teams 四大连接器合并为单一 Microsoft Graph 流程（覆盖 66 项动作并支持最小权限）；注意它不会自动迁移，管理员需按指南手动切换现有 agent。第二，AlloyDB Express 进入 Public Preview，coding agent 可在两秒内拉起带 ScaNN 向量检索的隔离 PostgreSQL 实例，支持 scale-to-zero（闲置计算 $0）并平滑升至生产 AlloyDB。

⚡ 90-Second Advisor Brief · Deferred Tier, Gateways & AlloyDB Express
